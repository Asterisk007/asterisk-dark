## Installation

#### Via VS Code marketplace

Click the Install button

#### Via source

1. `git clone https://github.com/Asterisk007/asterisk-dark`
2. `cd asterisk-dark`
3. `npm install -g @vscode/vsce`
4. `vsce package`
5. Open the command palette in VS Code - Ctrl+Shift+P (or Cmd+Shift+P on Mac), then type "Extensions: Install from VSIX" and select that command
6. Navigate to where you cloned the repository, and select asterisk-dark.vsix
